# Worker PKL

Система для обнаружения машин на парковках с использованием компьютерного зрения и обработки изображений.

## Требования

- [uv](https://docs.astral.sh/uv/) - менеджер зависимостей Python
- [just](https://just.systems/) - простые макросы

### Just команды

- `just prepare` - установка и синхронизация зависимостей
- `just run` - запуск приложения
- `just lint` - проверка кода с помощью ruff (линтер)
- `just format` - форматтер кода
- `just qa` - комплексная проверка качества (форматирование + линтинг)
