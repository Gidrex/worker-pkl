# Бенчмаркинг и Мониторинг

**TLDR**

Рецепт `just benchmark <video path>` запускает benchmark по определённому video(должно так же с url RTSP сервера работать).
Скрипт `scripts/bench_metrics.sh` предоставляет дашборд в реальном времени и итоговый отчёт об использовании системных ресурсов(CPU, RAM, GPU и VRAM) для Python процесса.
Ваш report.md создайте в `benchmarks/<your username>/report.md` и в этой же директории переносите ваши `config_run<1,2,3...>.json`.

`report.md`
```md
## Первый h2 - это ваше железо, например:

*   **CPU:** 11th Gen Intel(R) Core(TM) i5-11400H (12 cores) @ 4.50 GHz
*   **RAM:** 16GB DDR4
*   **GPU:** NVIDIA GeForce RTX 3060 Laptop
*   **OS:** Linux

## Второй h2 - Все ваши запуски с эксперементированием настроек

### первый h1 = Run 1:
Самое главное перечислить средную загруженность железа(желательно в виде таблички) и ваши наблюдения.
```

## Требования

Для запуска скрипта в вашей системе должны быть доступны следующие утилиты.

### Стандартные утилиты Linux
Обычно они предустановлены в большинстве дистрибутивов Linux (Ubuntu, Debian, Fedora, Arch и т.д.):

*   **`bash`**: Интерпретатор командной строки.
*   **`ps`** (procps): Для получения статистики по процессам (CPU, RAM).
*   **`awk`**: Для арифметических вычислений и обработки текста.
*   **`grep`**: Для фильтрации текста.
*   **`nproc`** (coreutils): Для подсчёта ядер процессора (используется для нормализации).
*   **`tr`, `head`, `date`, `sleep`, `mktemp`, `rm`, `xargs`**: Базовые утилиты.

### Специфичные утилиты
Требуются для мониторинга GPU:

*   **`nvidia-smi`**: Часть проприетарного драйвера NVIDIA для Linux.
    *   *Примечание:* Если эта утилита отсутствует, скрипт не сможет сообщать метрики GPU/VRAM.

## Дашборд в реальном времени
Обновляется каждую 1 секунд (настраивается переменной `INTERVAL` внутри скрипта).

```text
Monitoring PID: 137382
----------------
GPU: 70%
VRAM: 1202 / 6144 MiB
CPU: 9.7%
RAM: 1.59 GB
```

### Итоговый отчёт (Summary)
Когда процесс завершается или вы останавливаете скрипт (Ctrl+C), генерируется отчёт:

```text
    BENCHMARK SUMMARY (PID: 137382)
------------------------------------------
CPU (Proc): Avg: 9.7%  | Max: 9.8%
RAM (Proc): Avg: 1.59 GB | Max: 1.67 GB
GPU (Glob): Avg: 50.5%  | Max: 86.0%
VRAM (Pr):  Avg: 1040 MiB | Max: 1202 MiB
```
