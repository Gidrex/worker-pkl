# Система Отслеживания Транспортных Средств - Руководство Пользователя

## Установка

```bash
just sync
```

## Рабочий процесс

**Что делает система:**
1. Сканирует `./videos/` на наличие всех видеофайлов (.mp4, .avi, .mov, .mkv, .flv)
2. Извлекает каждый N-й кадр из видео (значение N берется из конфигурации, по умолчанию: 5)
3. Автоматически размечает транспортные средства с использованием предварительно обученной модели **[YOLOv12](https://docs.ultralytics.com/)**
4. Разделяет данные на 80% для обучения и 20% для валидации
5. Создает метрики в процессе работы в data/ . По ним можно узнать закруженность парковки в разное время, а так же при DEBUG уровне смотреть как кадры размечаются

**Визуализация:**
- Зеленые рамки = ПРИПАРКОВАННЫЕ транспортные средства
- Красные рамки = ДВИЖУЩИЕСЯ транспортные средства
- Желтые рамки = НЕИЗВЕСТНО (недостаточно кадров)

## Поддерживаемые форматы видео

- `.mp4`
- `.avi`
- `.mov`
- `.mkv`
- `.flv`
