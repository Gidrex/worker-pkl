# Руководство Разработчика

## Виртуальный RTSP Сервер

Этот проект включает встроенное окружение для эмуляции IP-камер (RTSP-серверов) на базе **[FFmpeg](https://ffmpeg.org/)** и **[MediaMTX](https://github.com/bluenviron/mediamtx)**. Это позволяет разрабатывать и тестировать функционал потоковой передачи без доступа к физической камере, по средсвом создания виртуальной камеры и транслирования видеопотока на неё.

### Предварительные требования

Для использования виртуального сервера необходимо установить [пакетный менеджер Nix](https://nixos.org/download/).

1. Войдите в виртуальное окружение:
   ```bash
   nix develop
   ```

### Основные команды

Внутри окружения nix flake доступны следующие инструменты:

1.  **Запуск Эмуляции Камеры (Одной командой):**
    ```bash
    fake-cam ./videos/video.avi
    ```
    Поток будет доступен по адресу: `rtsp://localhost:8554/cam1`

2.  **Ручная Настройка:**
    
    *Терминал 1 (Сервер):*
    ```bash
    mediamtx ./mediamtx.yml
    ```
    
    *Терминал 2 (Стример):*
    ```bash
    ffmpeg -re -stream_loop -1 -i ./videos/video.avi -c copy -f rtsp rtsp://localhost:8554/cam1
    ```

### Просмотр и Использование

*   **Проверка потока (через MPV player):**
    ```bash
    mpv rtsp://localhost:8554/cam1
    ```

*   **Запуск Нейронки на потоке:**
    ```bash
    uv run src/main.py process rtsp://localhost:8554/cam1
    ```

## Команды Разработки
